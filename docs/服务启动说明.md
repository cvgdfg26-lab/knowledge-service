```powershell
backend/.venv/Scripts/python scripts/cpu_port_forward.py
```

该脚本从 `prompt/.env` 读取已提供的 CPU SSH 连接数据，使用 `.cache/remote/known_hosts` 校验已记录的主机密钥。需要本地 `.cache/ssh-tools` 中的 Paramiko；本次已经安装。若清理了该目录，可执行 `uv pip install --target .cache/ssh-tools paramiko==5.0.0` 恢复。

## CPU 运维命令

连接 CPU 后在项目目录执行；这些命令仅管理 `knowledge-remote` 项目：

```bash
cd /home/ubuntu/knowledge-service
sudo -n docker compose --env-file .env.remote -f infra/compose.remote.yml ps
sudo -n docker compose --env-file .env.remote -f infra/compose.remote.yml logs --tail 100 kb-worker
sudo -n docker compose --env-file .env.remote -f infra/compose.remote.yml up -d --no-build mongodb kb-import kb-query kb-worker gateway
sudo -n docker compose --env-file .env.remote -f infra/compose.remote.yml run --rm --no-deps kb-admin doctor --models
```

业务容器配置 `restart: unless-stopped`；GPU 进程在 GPU 计算容器重启后需要重新启动，尚未设置进程自动重启管理。停止本项目时使用同一 Compose 文件的 `stop`，保留数据卷。

新增环境首次初始化才执行 `kb-admin init-mongo`、`migrate`、`seed-demo`。本次已执行，日常启动不需要重复初始化。不要对现有共享 Milvus 执行新环境 `init-infra`，该命令还会初始化账户。
